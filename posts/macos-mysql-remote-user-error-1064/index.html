MacOS MySQL 원격 접속 사용자 생성, MySQL ERROR 1064 해결

ERROR 1064 (42000): You have an error in your SQL syntax; check the manual that corresponds to your MySQL server version for the right syntax to use near '('Dkagh1234!'),'','','')' at line 2

-> 버전이 달라서 생긴 에러. 해결법은 아래에 있음.

최초 로그인



mysql -u root -p

사용자 확인



select Host,User FROM mysql.user;

버전 확인



SELECT VERSION();

나는 8.0 버전.

mysql 유저 생성하기

[ 8.0 버전 ]



CREATE USER 'root'@'%' IDENTIFIED BY '패스워드';

[ 5.7 버전 ]



GRANT ALL PRIVILEGES ON *.* TO 'root'@'%' IDENTIFIED BY 'Dkagh1234.';

유저명에 원하는 유저명을 작성해주고 뒷부분에 '' 작은따옴표안에 유저가 사용할 비밀번호를 지정해준다.

정상적으로 mysql의 유저가 생성이 되었다면,

명령어 입력후에 엔터를 입력 후 Query OK 라는 피드백을 받을 수 있다.

8.0 버전 | mysql 유저권한주기



GRANT ALL PRIVILEGES ON *.* TO 'root'@'%';

GRANT ALL ( 모든 권한을 준다 )

ON *.* (모든 데이터베이스에 접속할수 있다.

만약 특정 디비와 테이블을 지정해주고 싶다면

on test.test로 지정해주면된다. 그럼 test디비에 test테이블에 권한을 준다는 뜻)

TO (누구에게) = 'root'@'%'; 



GRANT GRANT OPTION ON *.* TO 'root'@'%';
