- 사용자는 티켓 발행기를 이용해 티켓을 발행 받을 수 있음.

- 티켓 발행기는 딱 하나만 존재.

- 발행된 티켓은 고유의 시리얼 번호가 있음.

- 티켓의 시리얼 번호는 0보다 크고,

0인 시리얼 번호는 유효하지 못한 티켓을 의미함.

- 발행될 수 있는 티켓 개수는 한정되어 있음.

interface Ticket {
** 유효한 티켓인지/아닌지 판단하기 위해, 티켓 넘버 반환 가능하게.
public int getTicketNum();
	넘버가 0인지- 0보다 작냐로 판단. 크면 유효하고 작으면 문제 있는 티켓이라 판단하게.
}




class NormalTicket implements Ticket {
** 티켓 시리얼 넘버 갖고 있게.
private int serial_num;
public NormalTicket(int num) {
this.serial_num = num;
}

	@Override
	public int getTicketNum() {
return this.serial_num;
}
}




class ErrorTicket implements Ticket {

	@Override
	public int getTicketNum() {
// TODO Auto-generated method stub
return 0;
}
** 에러 티켓은 시리얼 번호 부여받을 필요가 없다. 무조건 0이기 때문!
}
