[ MAC Os apache 실행 ] 맥 아파치 실행, apachectl 옵션

맥에서 아파치 다운로드

는 이미 깔려 있어서 다운로드 받을 필요 없이 터미널에서



sudo apache start

하면 실행된다ㅎㅎ

명령어 입력하고

127.0.0.1 로 접속해서 "It works!" 뜨면 실행 잘 된 것.

* - - - - - -

apachectl 옵션

- - - - - - -

start

stop

restart

fullstatus : 아파치 서버의 실행상태를 자세히 보여준다.

status : 아파치 서버의 상태를 간단히 보여준다.

graceful : 아파치를 SIGUSR1을 보내 재시작 혹은 시작한다.

configtest : httpd.conf 파일의 설정상태를 점검해 준다.

help : 옵션에 대한 도움말을 보여준다.

https://httpd.apache.org/docs/2.4/ko/programs/apachectl.html
