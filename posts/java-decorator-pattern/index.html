[Java] 디자인 패턴: 데코레이터(Decorator) 패턴

데커레이터 패턴:

본 기능에 추가할 것이 많을 때 사용하기 좋다!

왜 그런지 알아보기 위해

지금부터 우리가 내비게이션 소프트웨어를 만드는 사람이라고 생각하고 한 가지 예제를 살펴보자.

우선, 뭐가 필요할까?

1) 도로 표시

- RoadDisplay 클래스 : 기본 도로 표시 기능을 제공하는 클래스.

- RoadDisplayWithLane : 도로가 그려져야 한다. 그리고 기본 도로 표시에 추가 적으로 차선을 표시하는 클래스가 필요하다.



a.
class RoadDisplay {
public void draw() {
		System.out.println("기본 도로 표시");
}
}

a는 그냥 도로를 만들어주는 코드.

| | 이렇게..



b.
class RoadDisplayWithLane extends RoadDisplay {
public void draw() {
super.draw();
drawLane();
}
private void drawLane() {
		System.out.println("차선 표시");
}
}

RoadDisplayWithLane는 차선.

RoadDisplay를 상속 받아서, 가지고 있는 기능(도로)을 사용할 수 있게 했다.

차선을 그릴수도, 도로를 그릴 수도 있다.

또 draw 메서드를 재정의를 통해

부모가 가지고 있는 기능을 수행하고

차선을 그리는 자기의 기능을 수행한다. (물론 편의상 텍스트로만..)



c.
public class Client {
public static void main(String[] args) {
		RoadDisplay road = new RoadDisplay();
		road.draw();

		RoadDisplay roadWithLane = new RoadDisplayWithLane();
		roadWithLane.draw();
}
}

메인 함수!

2) 문제점

다른 추가적인 도로 표시 기능을 구현하고 싶다면 어떻게 해야할까?

또.. 그 여러가지 추가 기능이 들어왔을 때, 그 조합은 어떻게 할까?

코드 중복을 피하면서, 생각해 보자!

RoadDisplay

- draw : void

RoadDisplayWithLane

- draw : void

- drawLane : void

RoadDisplayWithTraffic

- draw : void

- drawTraffic : void

 


d. 추가 기능

class RoadDisplayWithTraffic extends RoadDisplay {

super.draw();
drawTraffic();
}

		System.out.println("교통량 표시");

추가 기능 별로 '개별적인' 클래스를 설계하고, 이를 조합하는 방식으로 생각해 보자.

3) 해결 코드



a.
abstract class Display {
public abstract void draw();
}
class RoadDisplay extends Display {
public void draw() {
		System.out.println("기본 도로 표시");
}
}
class DisplayDecorator extends Display {
private Display decoratedDisplay;
public DisplayDecorator(Display decoratedDisplay) {
this.decoratedDisplay = decoratedDisplay;
}
public void draw() {
		decoratedDisplay.draw();
}
}


b.
class LaneDecorator extends DisplayDecorator {
public LaneDecorator(Display decoratedDisplay) {
super(decoratedDisplay);
}
public void draw() {
super.draw(); // 도로, 부모 기능
drawLane(); // 차선, 자기가 가진 기능
}
private void drawLane() {
		System.out.println("\t차선 표시");
}
}


d.
class TrafficDecorator extends DisplayDecorator {
public TrafficDecorator(Display decoratedDisplay) {
super(decoratedDisplay);
}
public void draw() {
super.draw();
drawTraffic();
}
private void drawTraffic() {
		System.out.println("\t교통량 표시");
}
}


c.
public class Client {
public static void main(String[] args) {
		Display road = new RoadDisplay();
		road.draw();

		Display roadWithLane = new LaneDecorator(new RoadDisplay());
		roadWithLane.draw();

		Display roadWithTraffic = new TrafficDecorator(new RoadDisplay());
		roadWithTraffic.draw();
}
}

새로운 기능들을 만들려면

상속받는 기능들만 넣어주면 된다!

조합을 위해 새로운 클래스를 만드는 것이 아니라,

기본 클래스에 + 생성자 에 어떤 것을 넣냐에 따라 기능이 추가된다! 짱짱★



Display roadWithLane = new LaneDecorator(new RoadDisplay());
roadWithLane.draw();

abstract class Display {
public abstract void draw();
}
class RoadDisplay extends Display {
public void draw() {
		System.out.println("기본 도로 표시");
}
}
class DisplayDecorator extends Display {
private Display decoratedDisplay;
public DisplayDecorator(Display decoratedDisplay) {
this.decoratedDisplay = decoratedDisplay;
}
public void draw() {
		decoratedDisplay.draw();
}
}
class LaneDecorator extends DisplayDecorator {
public LaneDecorator(Display decoratedDisplay) {
super(decoratedDisplay);
}
public void draw() {
super.draw();
drawLane();
}
private void drawLane() {
		System.out.println("\t차선 표시");
}
}
class TrafficDecorator extends DisplayDecorator {
public TrafficDecorator(Display decoratedDisplay) {
super(decoratedDisplay);
}
public void draw() {
super.draw();
drawTraffic();
}
private void drawTraffic() {
		System.out.println("\t교통량 표시");
}
}
class CrossingDecorator extends DisplayDecorator {
public CrossingDecorator(Display decoratedDisplay) {
super(decoratedDisplay);
}
public void draw() {
super.draw();
drawCrossing();
}
private void drawCrossing() {
		System.out.println("\t횡단보도 표시");
}
}
