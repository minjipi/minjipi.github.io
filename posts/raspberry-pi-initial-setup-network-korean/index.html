0. 라즈베리파이에 운영체제(라즈비안) 설치하기

(1) 라즈비안 다운

https://www.raspberrypi.org/downloads/raspbian/ 에 접속해서

Raspberry Pi OS (32-bit) with desktop and recommended software 설치파일을 다운

(2) SD 카드 연결 SD카드를 USB 리더기에 연결 후 PC에 연결

(3) 설치 프로그램 설치 및 라즈비안 설치

https://www.balena.io/etcher/ 에 접속하여 Etcher를 설치 후 실행

1. Flash From File : 다운로드 받은 라즈비안 압축파일 선택

2. Select Target : 라즈비안을 설치할 Micro sd card 드라이브 선택

3. Flash 버튼을 클릭하면 Micro sd card에 세팅

1. 네트워크 설정

(1) SSH enable 설정 파일 생성

SD카드 최상위 폴더에 파일이름이 ssh 인 파일을 생성, 내용 및 확장자는 없음

메모장 혹은 vi로 파일을 만들어 줍니다.

(2) Wifi 접속 설정 (친구컴의 랜선으로 할거면 상관없음)

SD카드 최상위 폴더에 파일이름이 wpa_supplicant.conf 파일 생성 



﻿ctrl_interface=DIR=/var/run/wpa_supplicant GROUP=netdev
update_config=1
network={
      ssid= "접속할 공유기의 이름" // "" 요거 있어야 함
	  psk="접속할 공유기의 PW"
}

요렇게 파일이 두개 만들어졌나요?

2. 초기설정

- sudo raspi-config 입력 후 설정

- Interfacing Options -> SSH -> Yes 를 선택하여 SSH를 활성화

- Interfacing Options -> VNC -> Yes 를 선택하여 VNC 서버를 활성화

- Advanced Options -> Resolution -> DMT Mode 9 를 선택하여 기본 해상도를 설정

* Default 값만 아니면 됨.

- Finish 를 선택.
