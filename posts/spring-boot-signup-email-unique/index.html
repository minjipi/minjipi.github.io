[Spring Boot] 회원가입 이메일 중복 검사 (Unique 제약 조건)

JPA springboot 멤버가입 이메일 중복 로직을 구현하며..

코드만 봤을 때 다음의 문제점 무엇일까?



private void validMemberEmailDuplicate(String email) {
if (memberRepository.existsByEmail(email))
throw new MemberEmailDuplicateException("이미 사용중인 이메일 입니다.");
}

동일한 멤버 아이디가 중복 가입이 될 수 있다는 것이다.. was가 동시에 여러개 뜨는데(멀티스레드) 예를들어 '멤버A' 라는 사용자가 정말 동시에 DB insert를 하게 되면, 동시에 '멤버A'라는 회원이 두 명 가입되는 문제가 생긴다. 이런 문제가 생길 때 최후의 방어를 위해 DB member email에 Unique 제약조건을 걸어둬야 한다.

* Unique 제약조건:

입력하지 않아도 되지만 중복된 값은 저장되지 못하게 하는 제약조건. null값('')은 허용하지만 동일한 값이 저장되는 것만은 허용하지 않는다.

+ 실무자 분께서는 위 방식 말고 INSERT 쿼리에 조건을 거는 방법을 사용한다고 한다.
