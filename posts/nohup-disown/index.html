[nohup, disown 명령어] 무중단 서비스 nohup, disown

터미널로 접속해서 명령어를 실행한 후, 해당 터미널을 종료해도 계속 명령어가 실행되도록 유지하고 싶을 때 nohup 명령어를 사용한다. 무중단 서비스를 위해 nohup을 이용하여 백그라운드에서 실행시키자.

nohup



nohup java -jar build/libs/demo-0.0.1-SNAPSHOT.jar & > /dev/null

nohup: ignoring input and appending output to ‘nohup.out’

&는 백그라운드로 명령어를 실행하라는 것이다.

만약 &를 빼고 해서 실행했다면, 그냥 Ctrl+Z를 눌러 백그라운드로 돌릴 수 있다.

nohup으로 실행할 경우 화면에 출력될 내용이 기본적으로 nohup.out 파일로 리다이렉트 되는데 다음 명령어로 로그를 확인할 수 있다.



cat nohup.out

nohup 으로 실행중 nohup.out 을 비우고 싶다면, 아래 명령어를 사용하면 된다.



cat /dev/null > nohup.out

이렇게 해도 세션종료와 동시에 프로세스가 죽는다면 disown 옵션을 추가하면 된다.

disown

disown은 프로세스 작업의 소유권을 shell session에서 해제시키는 옵션이다. 옵션으로 추가해주면 현재 session job list에서 job 들이 빠져나가게 된다. (jobs 명령어로 확인 가능, 프로세스 전체 보기로 보면 프로세스는 남아있는 것을 볼 수 있다.) 실행 후 아래 명령어를 추가로 터미널에 쳐주면 된다.



disown -h

프로세스 종료

이제 nohup으로 백그라운드에서 실행중인 프로세스를 종료시켜보자.

1. PID를 알고있다면



sudo kill -9 {PID}

명령어를 이용하여 프로세스를 중단시키면 되고

2. PID를 잊어버렸다면



ps -ef | grep {실행시켰던 파일이름}

위 명령어를 이용하면 된다.
