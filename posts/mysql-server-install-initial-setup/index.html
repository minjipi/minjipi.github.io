[MySQL] MySQL 서버 설치와 초기 설정, 기본 비밀번호 바꾸기

본체에 SQL Workbrench 클라이언트 프로그램 설치,

가상머신에 CentOS7 서버 컴퓨터를 설치하고 sql server 설치.

mySQL server 설치



sudo yum -y install https://dev.mysql.com/get/mysql80-community-release-el7-3.noarch.rpm





yum -y install mysql-community-server

시스템 재시작



systemctl restart mysqld

확인 : 포트 확인:



netstat -anlp | grep :3306

Listen 상태인지 확인!

다시 본체의 MySQL Workbench 로 와서

MySQL Connections 에서 + 아이콘 클릭.

Local (127.0.0.1) 이랑,

가상머신 서버컴의 IP 입력.

이렇게 생성된 상태.

이제 저 서버 컴퓨터에 접속하려면? 일단

방화벽 끄기



systemctl stop firewalld

여기까지 설치만 했지 설정을 안한 상태라 접속이 안된다.

MySQL 초기설정:

1. 아래 명령어로 패스워드 확인.



cat /var/log/mysqld.log | grep password

2. 기본 설정된 비밀번호를 내가 알기 쉬운걸로 바꾸자.



mysql_secure_installation

이렇게 변경하면 되는데

새 암호 입력 시 몇가지 물어보는게 있다. 여기서 주의 할 것:

Disallow root login remotely? 에서는 NO

나머지 질문엔 다 y.

지금 난 원격 접속을 하려는 거라 저 질문엔 NO를 해야함.

다 끝났다면 이제 접속해보자!



접속 명령어:
mysql -u root -p

그리고 방금 설정한 패스워드 입력하고,

사용자를 확인해보자.
