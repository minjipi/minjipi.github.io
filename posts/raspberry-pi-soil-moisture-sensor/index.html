Raspberry Pi :: 라즈베리파이 '토양 수분센서'

토양 수분센서는 토양의 수분이 얼만큼 있는지 특정하는 소자.

그런데 라즈베리파이는 DAC(Digital-Analog Converter) 뿐 아니라

ADC(Analog-Digital Converter) 장치도 내장하고 있지 않다.

그래서 아날로그 전압을 입력받으려면,

아날로그 신호를 디지털로 변환해 주는 ADC를 통해 변환된 디지털 신호를 받고,

받은 신호를 라즈베리파이에서 읽기 위해

라즈베리파이에서 SPI 프로토콜을 사용할 수 있게 해주어야 한다.

라즈베리파이에서 SPI 프로토콜을 사용할 수 있게 되었다면

이제 ADC 기능을 가진 MCP3008 IC를 이용해

아날로그에서 변환된 디지털 값을 SPI 통신을 통해 받아오자.



import spidev, time

spi = spidev.SpiDev()
spi.open(0,0)
spi.max_speed_hz = 100000

def analog_read(channel):
	r = spi.xfer2([1, (8 + channel) << 4, 0])
	adc_out = ((r[1]&3) << 8) + r[2]
return adc_out



while True:
	reading = analog_read(0)
	voltage = reading * 3.3 / 1024
print("Reading=%d\tVoltage=%f" % (reading, voltage))
	time.sleep(1)
