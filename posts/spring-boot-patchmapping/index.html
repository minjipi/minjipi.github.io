[Spring Boot] @PatchMapping 사용법

데이터 일부를 수정할 때 사용하는 HTTP PATCH 메소드.

HTTP PATCH 메소드는 데이터 일부를 수정할 때 사용한다.

HTTP PUT 메소드와 다른 점은 HTTP PATCH 메소드의 경우, 수정하기로 명시한 데이터만 갱신되고 나머지 데이터는 그대로인데

HTTP PUT의 경우 수정하기로 명시되지 않은 나머지 데이터는 모두 "빈 값"이 된다.

@PatchMapping 사용하기

1. 컨트롤러 클래스안에 요청 처리 메소드를 작성한다.

SampleController.java



@PatchMapping("/sample/patch-mapping/{id}")  
@ResponseBody  
public String samplePatchMapping(  
    @PathVariable("id") Integer id,  
    @RequestBody SampleRequestDTO sampleRequestDTO  
) {
return "this is patch mapping example. id = " + String.valueOf(id)
+ "\n"
+ sampleRequestDTO.toString();
}

@RequestBody 어노테이션으로 JSON 파라미터를 전달받는다.

ex)



@RequestBody SampleRequestDTO sampleRequestDTO

HTTP PATCH 요청이 올 때만 자바 메소드가 실행된다.

ex)



@PatchMapping("/sample/patch-mapping/{id}")

2. POSTMAN을 통해 실행.

PATCH http:/localhost:8080/sample/patch-mapping/3

content-type: application/json 



{
"age" : 1000,
"hobby" : "sleep"
}

3. 실행 결과



this is patch mapping example. id = 3
name : null, age : 1000, hobby : sleep
