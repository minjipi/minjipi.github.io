** 💡setenforce 0 란?

MAC 기반의 보안 커널을 리눅스에 이식한 커널 레벨의 보안 모듈인 SELinux의 모드 enforce, permissive, disable 중 permissive mode 모드로 전환할 수 있는 명령어.

SELinux 는 enforce, permissive, disable 3 가지 모드가 있으며 기본 설정은 enforce mode이고 보안 정책에 위배되는 모든 액션이 차단된다.

permissive mode 는 경고 메시지를 내고 차단하지는 않음.

모드의 전환은 setenforce 명령어를 사용하면 되며, 옵션으로 1을 주면 enforce mode. 0 일 경우 permissive mode 로 전환할 수 있다.
